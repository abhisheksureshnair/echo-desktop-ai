Enable Echo Co-pilot

Quickly add the Echo sidebar directly into your web browser pages in less than a minute.

1
Open a new tab in Chrome and go to: chrome://extensions
2
Enable the Developer mode switch in the top-right corner.
3
Click the "Load unpacked" button in the top-left corner.
4
Select the chrome folder inside the browser-extension folder:
/browser-extension/chrome
1
Open a new tab in Brave and go to: brave://extensions
2
Enable the Developer mode switch in the top-right corner.
3
Click the "Load unpacked" button.
4
Select the brave folder inside the browser-extension folder:
/browser-extension/brave
1
Open a new tab in Edge and go to: edge://extensions
2
Turn on the Developer mode switch in the bottom-left sidebar.
3
Click the "Load unpacked" button at the top of the screen.
4
Select the edge folder inside the browser-extension folder:
/browser-extension/edge
1
Open Firefox and navigate to: about:debugging
2
Click on "This Firefox" in the left-hand navigation sidebar.
3
Click the "Load Temporary Add-on..." button.
4
Navigate inside the firefox folder under browser-extension, and select the manifest.json file itself:
/browser-extension/firefox/manifest.json
⚠️ Note: Firefox requires you to select a file. Do not select the folder; open the folder and double-click the manifest.json file to load.
